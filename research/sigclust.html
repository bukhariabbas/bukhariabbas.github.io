SigClust: evidence for cluster annotation

From signature scores to supported annotations

A high gene-signature score does not by itself establish whether a program is concentrated in a particular cluster. I developed SigClust to evaluate that association in an already clustered Seurat object and return annotations alongside the statistical evidence.

How it works

For each retained signature, the workflow identifies cells above a specified score percentile and tests their over-representation in each cluster using a one-sided Fisher test. Odds ratios summarize effect size, and Benjamini–Hochberg correction addresses multiple testing.

The full multi-signature profile is retained alongside a dominant supported annotation. Inputs can include scores from UCell, AUCell, AddModuleScore, or another compatible procedure. Outputs include enrichment and annotation tables, parameter summaries, heatmaps, and a functional UMAP.

Interpretation

SigClust annotates existing clusters; it does not discover clusters or independently establish cell identity. Results depend on the signatures, score thresholds, and upstream clustering. The useful output is an inspectable relationship between a proposed label and the evidence supporting it.
