# bukhariabbas.github.io

Personal academic website for Syed Abbas Bukhari, PhD.

## Local preview
```bash
python3 -m http.server 8000
```
Visit http://localhost:8000

## Deploy
Auto-deploys to GitHub Pages from the `main` branch.

## Update CV
Replace `assets/cv.pdf` and push.

## Add headshot
Drop `assets/headshot.jpg` (square) and push.
