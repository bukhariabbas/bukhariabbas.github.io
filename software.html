R / Single-cell annotation

SigClust

Connect existing cell clusters with gene signatures.

SigClust uses signature–cluster enrichment, effect sizes, and false-discovery-rate control to support annotation of an existing single-cell analysis.

It takes supplied clusters and compatible per-cell scores. The result depends on the signatures and upstream analysis; it is an annotation workflow, not a clustering or deconvolution algorithm.
