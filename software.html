SigClust

Signature-based annotation of existing single-cell clusters, with enrichment tests, effect sizes, and false-discovery-rate control.

  • R
  • Seurat
  • UCell / AUCell scores
  • MIT declaration
View source on GitHub ↗Read the case study ↗

Public repository example. Select to enlarge.

Clear inputs.
Reviewable outputs.

Start with an existing clustered Seurat object and a compatible score matrix. The workflow returns signature–cluster enrichment, annotations, parameter summaries, and figures.

SigClust annotates supplied clusters; it is not a clustering or deconvolution algorithm. Interpretation depends on signature quality and upstream analysis.

R / EXAMPLE USAGE
source("sigclust_annotate.R")

# Existing Seurat clusters + per-cell signature scores
results <- sigclust_annotate(
  seurat_obj = obj,
  scores = scores,
  output_dir = "results/",
  label = "my_analysis"
)

How I work

Reproducible scientific computing

R, Python, Bash, version control, modular workflows, containers, and SLURM/HPC. I document decisions and keep parameters and outputs traceable.

AI-assisted development with scientific oversight

I use agentic coding to accelerate implementation within human-defined analysis plans. Code review, testing, provenance, statistical diagnostics, and biological interpretation remain essential.

Mentorship built into delivery

Written analysis plans, worked examples, and code review help colleagues develop independent computational reasoning and interpretation.

Evidence before automation

Analytical convenience does not replace study design or validation. Data access, scientific conclusions, and release decisions stay under human responsibility.
